    의료 데이터셋 상세 가이드¶

    🏥 의료 영상 (Medical Imaging)¶

    1️⃣ 주요질환 이미지 합성데이터 (X-ray) — ID: 71521¶

    항목 내용
    데이터명 주요질환 이미지 합성데이터(X-ray)
    생성 방식 합성 모델 (Synthetic)
    규모 105,000장 (5종 병변)
    영상 종류 Chest X-Ray, Mammography, PNS, Facial Bone
    참여 기관 컨소시엄 참여 의료기관
    용도 정상/병변 분류 모델 개발
    검증 방식 VTT(Visual Turing Test), 분류 모델 유사도 검증

    특징: - ✅ 개인정보 이슈 없음 (합성 데이터) - ✅ 서울대병원, 가톨릭대병원 등 대형병원 데이터 기반 - ⚠️ 제3자 이전/원본 추론 금지

    2️⃣ 주요질환 이미지 합성데이터 (MRI) — ID: 71552¶

    항목 내용
    데이터명 주요질환 이미지 합성데이터(MRI)
    생성 방식 합성 모델 (Synthetic)
    규모 10,000장 (Brain MRI)
    영상 종류 Brain MRI
    참여 기관 서울대학교 병원, 가톨릭대학교 병원 등
    데이터 형식 PNG (Normal/Abnormal 폴더 구조)

    특징: - ✅ Brain MRI에 특화 - ⚠️ 안심존 이용신청 필요 (보건의료 데이터)

    3️⃣ 주요질환 이미지 합성데이터 (CT) — ID: 71597¶

    항목 내용
    데이터명 주요질환 이미지 합성데이터(CT)
    생성 방식 합성 모델 (Synthetic)
    참여 기관 대형병원 컨소시엄

    🎙️ 의료 음성/대화¶

    비대면 진료를 위한 의료진 및 환자 음성 — ID: 208¶

    항목 내용
    데이터명 비대면 진료를 위한 의료진 및 환자 음성
    유형 음성 + 텍스트
    규모 의료진 700시간 (33,000문장) + 환자 600시간 (45만 문장)
    구성 의사 300시간, 간호사 400시간, 환자 45만 문장
    용도 비대면 진료 STT (음성인식) 서비스 개발
    AI 모델 ✅ 제공됨 (STT 인식률 검증)

    특징: - 직군별/직능별 의료진 음성 - 연령/성별/증상별 환자 음성 - COVID-19 이후 비대면 의료 수요 대응

    📚 의학 지식/텍스트¶

    1️⃣ 전문 의학지식 데이터 — ID: 71874 ⭐⭐⭐¶

    항목 내용
    데이터명 전문 의학지식 데이터
    생성 방식 LLM
    참여 기관 Big 5 대형병원 중 4개 (서울성모, 삼성서울, 서울대, 세브란스) + 보라매병원
    규모 1억 토큰 말뭉치 + 1.5만 쌍 질의응답 (10만 토큰)
    출처 학술논문, 저널, 온라인 의료정보, 정부/학회 가이드라인, 의학교과서, 동의서 등
    언어 한국어/영어 혼합

    진료과 (17개): 외과, 예방의학, 정신건강의학과, 신경과/신경외과, 피부과, 안과, 이비인후과, 비뇨의학과, 방사선종양학과, 병리과, 마취통증의학과, 의료법규, 기타, 산부인과, 소아청소년과, 응급의학과, 내과

    활용 예시: 

    Q: 35세 여성이 STRIBILD 과다 복용 후 내원...
   (임상 시나리오 기반 다지선다형 질문)

    특징: - ⭐ LLM 학습용 고품질 데이터 — 판독문 생성, 진료 보조 AI에 활용 가능 - ✅ 대규모 전문의 참여로 고품질 보장 - ⚠️ 보건의료 데이터 — 안심존(온라인/오프라인) 이용 필요

    2️⃣ 의료, 법률 전문 서적 말뭉치 — ID: 71487¶

    항목 내용
    데이터명 의료, 법률 전문 서적 말뭉치
    규모 1억 어절 (126,513건 원천데이터)
    출처 저작권 확보 전문 도서 + 특허(의료) + 판결문(법률)
    분야 의료 + 법률 (혼합)
    용도 Q&A 서비스, 진료과 추천, 판례 요약

    특징: - ✅ 저작권 문제 해결된 고품질 말뭉치 - ✅ 전문 용어 분포 분석 완료 - ✅ 의료/보건법 포함
