    Ki-67 Seed Map Caching¶

    개요¶

    Ki-67 디지털 병리 모델(PyTorch Lightning) 학습 속도 최적화 프로젝트. CPU 기반 데이터 증강(add_seed_map)이 병목으로 확인되어, seed map 디스크 캐싱으로 2.67x 학습 속도 향상 달성.

    배경¶

    병목 원인¶

    • add_seed_map 함수에서 scipy.convolve, distance_transform_edt, np.log x6 연산을 매 iteration, 매 epoch 반복
    • GPU 연산은 ~5ms/iter인데 CPU 증강이 ~250ms/iter 소요
    • RTX 4090의 80% 이상 시간을 데이터 대기로 낭비

    실험 환경¶

    항목 값
    GPU NVIDIA RTX 4090 (24GB)
    Framework PyTorch 1.12.1 + Lightning 1.9.2
    Data Ki67+ERPR_260327_train (subset)
    Model ResNet50+FPN+SpatialEmb (39.3M params)

    핵심 결과¶

    속도 최적화 실험 결과¶

    # 실험 Wall Time (s) Speed (it/s) Speedup
    0 Baseline (FP32) 115.3 3.69 1.00x
    0 AMP (FP16) 117.2 3.65 0.99x
    0 cuDNN Benchmark 118.6 3.65 0.97x
    0 Batch=4 116.4 1.84 0.99x
    0 Batch=8+AMP 115.1 2.20 1.00x
    1 pin_memory+persistent_workers 117.7 3.57 0.98x
    2 Seed Map Caching (cold) 154.0 9.52 2.58x
    2 Seed Map Caching (warm) 47.9 9.86 2.67x ✅
    3 GPU Seed (cold) 152.3 9.43 2.59x
    3 GPU Seed (warm) 48.0 9.70 2.41x

    결론¶

    • GPU 최적화 (AMP, cuDNN, batch size) → 모두 0% 개선 (병목이 GPU가 아님)
    • DataLoader 설정 (pin_memory, persistent_workers) → 0% 개선
    • Seed map 디스크 캐싱 → 2.67x 향상 🎉 (최초 1회만 cold start 비용)
