    MedGemma 파인튜닝 가이드¶

    📌 개요¶

    MedGemma는 두 가지 파인튜닝 방식을 지원한다:

    방식 설명 메모리 요구사항 소요 시간
    SFT Supervised Fine-Tuning A100 40GB+ 데이터 크기에 따라 다름
    QLoRA Quantized LoRA (효율적) A100 40GB+ SFT보다 빠름
    RLHF/GRPO 강화학습 A100 40GB+ ~11시간 (1700 steps)

    🖥️ 하드웨어 요구사항¶

    우리 연구소 환경¶

    GPU 추론 (4B) 추론 (27B) 파인튜닝 (4B) 파인튜닝 (27B)
    RTX 4090 (24GB) ✅ int4 가능 ❌ 불가 ❌ 불가 ❌ 불가
    RTX 5090 (32GB) ✅ fp16 가능 ⚠️ int4 가능 ❌ 불가 ❌ 불가
    A100 (40GB) ✅ 완전 지원 ✅ int4 가능 ✅ QLoRA/SFT ⚠️ QLoRA만
    A100 (80GB) ✅ 완전 지원 ✅ 완전 지원 ✅ 모든 방식 ✅ 모든 방식

    커스텀 데이터셋 만들기¶

    from datasets import Dataset, DatasetDict
from PIL import Image
import os

def create_medical_dataset(image_dir, labels_file):
    """
    이미지 디렉토리와 라벨 파일로부터 데이터셋 생성

    Args:
        image_dir: 이미지가 저장된 디렉토리
        labels_file: CSV 또는 JSON 라벨 파일
    """
    images = []
    labels = []

    # 이미지 로드 및 라벨 매핑
    for filename in os.listdir(image_dir):
        if filename.endswith(('.jpg', '.png', '.dcm')):
            img_path = os.path.join(image_dir, filename)
            images.append(Image.open(img_path))
            # 라벨 매핑 로직 추가

    return Dataset.from_dict({
        "image": images,
        "label": labels
    })

    🏃‍♂️ 파인튜닝 실행¶

    QLoRA 설정¶

    from transformers import BitsAndBytesConfig

# 4-bit 양자화 설정
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,
)

# 모델 로드
model = AutoModelForImageTextToText.from_pretrained(
    "google/medgemma-4b-it",
    quantization_config=bnb_config,
    device_map="auto"
)

    LoRA 어댑터 설정¶

    from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=16,                    # LoRA rank
    lora_alpha=32,          # LoRA alpha
    target_modules=[
        "q_proj", "k_proj", "v_proj", "o_proj",
        "gate_proj", "up_proj", "down_proj"
    ],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

model = get_peft_model(model, lora_config)

    SFT 트레이너 설정¶

    from trl import SFTTrainer, SFTConfig

sft_config = SFTConfig(
    output_dir="./medgemma-finetuned",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,
    bf16=True,                          # bfloat16 사용
    logging_steps=10,
    save_steps=100,
    eval_steps=100,
    save_total_limit=2,
    gradient_checkpointing=True,        # 메모리 절약
    optim="paged_adamw_8bit",          # 양자화 옵티마이저
)

trainer = SFTTrainer(
    model=model,
    args=sft_config,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    # 데이터 콜레이터 및 전처리 함수 추가
)

# 학습 시작
trainer.train()

    주요 메트릭¶

    메트릭 설명 목표
    loss 학습 손실 지속적으로 감소
    eval_loss 검증 손실 학습 손실과 비슷하게
    learning_rate 학습률 스케줄러에 따라 변화
    grad_norm 그래디언트 노름 급격한 증가 없어야 함
