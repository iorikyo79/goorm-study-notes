    MedGemma DICOM 통합 가이드¶

    📌 개요¶

    MedGemma는 DICOM 의료 영상 표준을 직접 지원한다. PACS 시스템과의 통합이 가능하다.

    DICOM 지원 방식¶

    방식 파라미터 데이터 타입 사용 사례 GPU 요구사항
    DICOM Store image_dicom DicomGenericData PACS 연동, 표준 임상 시스템 4090 int4 / A100 fp16
    GCS URI image_gcs GcsGenericData Google Cloud Storage 활용 4090 int4 / A100 fp16
    HTTP URL image_url HttpGenericData 외부 이미지 접근 4090 int4 / A100 fp16
    Raw Bytes image_bytes BytesGenericData 직접 파일 업로드 4090 int4 / A100 fp16

    🧠 배경 지식 (Background Knowledge)¶

    1. DICOM (Digital Imaging and Communications in Medicine)¶

    개념: 의료 영상을 표준화하여 다른 시스템 간 교환하기 위한 국제 표준

    주요 특징: - 1983년부터 개발 (ANSI/IEEE/ISO 표준) - DICOM Part 10: IOD (Information Object Definitions) - DICOM Part 15: Security - DICOM Part 16: Web Access to DICOM Objects (WADO) - 10,000+ 필드와 태그 정의

    주요 태그 예시: 

    (0008,0050) Study Instance UID          # 스터디 고유 식별자
(0010,0010) Patient Name               # 환자명
(0010,0020) Patient ID                 # 환자 식별자
(0008,0060) Modality                    # 이미지 유형 (CT, MR, XRAY)
(0020,000D) Study Instance UID
(0020,0010) Study ID
(0020,000E) Series Instance UID

    DICOM 파일 구조: 

    DICOM File
├── DICOM Header (100+ tags)
│   ├── Meta Information (File Meta)
│   ├── Transfer Syntax
│   ├── VR (Value Representation)
│   └── File Meta Information Group
└── DICOM Dataset (Image Data)
    ├── Pixel Data (실제 이미지)
    └── Private Tags

    2. DICOMweb (DICOM 표준의 웹 기반 버전)¶

    개념: DICOM 표준을 웹 프로토콜(HTTP)로 접근 가능하게 만든 것

    특징: - RESTful 디자인 (GET, POST, DELETE) - HTTP 기반 인증 - 웹 브라우저 및 API 클라이언트 지원 - FHIR 연동 가능

    주요 엔드포인트: 

    /studies/{study_uid}                    # 스터디 전체
/studies/{study_uid}/series             # 시리즈 목록
/studies/{study_uid}/instances          # 인스턴스 목록
/instances/{instance_uid}               # 특정 인스턴스
/instances/{instance_uid}/metadata      # 메타데이터
/instances/{instance_uid}/frame         # 특정 프레임
/instances/{instance_uid}/thumbnail     # 섬네일

    WADO-RS (RESTful): 

    GET /studies/{study_uid}/instances/{instance_uid}/rendered

    WADO-URI (리소스 로드): 

    GET /studies/{study_uid}/instances/{instance_uid}/file

    C-STORE (서버로 보내기): 

    POST /studies

    사용 예시: 

    # WADO-URI로 이미지 다운로드
response = requests.get(
    "https://pacs.example.com/dicomweb/studies/1.2.3.4/instances/1.2.3.5/file"
)
image_data = response.content  # DICOM 파일

# WADO-RS로 이미지 렌더링
response = requests.get(
    "https://pacs.example.com/dicomweb/studies/1.2.3.4/instances/1.2.3.5/rendered",
    headers={"Accept": "image/jpeg"}
)
image_data = response.content  # JPEG 이미지

    3. PACS (Picture Archiving and Communication System)¶

    개념: 의료 영상의 보관, 전송, 표시를 관리하는 시스템

    구성: 

    PACS
├── DICOM Storage SCP (서버)
│   ├── Archive (보관)
│   ├── Retrieval (조회)
│   └── Quality Control (품질 관리)
├── RIS (Radiology Information System)
├── HIS (Hospital Information System)
└── Worklist (작업 목록)

    PACS와 MedGemma 연동: 

    환자 스캔 → PACS에 DICOM 저장
      ↓
MedGemma 자동 분석 트리거
      ├─ 흉부 X-ray: 폐결절, 심비대 검출
      ├─ CT: 출혈, 종양 검출
      └─ 병리 슬라이드: 암세포 분석
      ↓
분석 결과 PACS/RIS에 저장
      ↓
의사 확인 (2차 독수용)

    📊 3D 볼륨 처리 (CT/MRI)¶

    개념¶

    CT/MRI 볼륨 처리: - 하나의 스터디에 수백~수천 개의 슬라이스 포함 - 각 슬라이스는 서로 연속적 (Z축 방향) - 전체 볼륨을 단일 이미지로 처리 어려움 - 따라서 선택적 슬라이스 처리 또는 병렬 처리

    코드 예시¶

    import concurrent.futures
import io
import requests
from PIL import Image
import numpy as np

def download_dicom_instance(dicom_instance):
    """
    DICOM 인스턴스 다운로드

    Args:
        dicom_instance: {'uri': str, 'instance_uid': str}

    Returns:
        PIL.Image 또는 None
    """
    try:
        response = requests.get(dicom_instance["uri"], timeout=30)
        response.raise_for_status()

        # DICOM 파일에서 이미지 추출 (pydicom 필요)
        from pydicom import dcmread

        with io.BytesIO(response.content) as pd:
            ds = dcmread(pd)
            image = ds.pixel_array

        # DICOM 모드로 변환 (0-255 → 0-1 float)
        image = image.astype(np.float32)
        if image.max() > 255:
            image = (image / 65535.0) * 255.0
        image = image.astype(np.uint8)

        # PIL Image 변환
        image = Image.fromarray(image).resize((224, 224))
        return image

    except Exception as e:
        print(f"다운로드 실패: {e}")
        return None

def process_dicom_volume(dicoms, selected_slices=None):
    """
    DICOM 볼륨 처리

    Args:
        dicoms: 인스턴스 목록 [{'uri': str, 'instance_uid': str}]
        selected_slices: 선택할 슬라이스 인덱스 (None이면 중앙 슬라이스)

    Returns:
        PIL.Image 또는 List[PIL.Image]
    """
    # 병렬 슬라이스 다운로드
    with concurrent.futures.ThreadPoolExecutor(max_workers=3) as executor:
        results = list(executor.map(download_dicom_instance, dicoms))

    # 유효한 이미지만 필터링
    images = [r for r in results if r is not None]

    if len(images) == 0:
        raise ValueError("유효한 이미지가 없습니다.")

    # 슬라이스 선택
    if selected_slices is not None:
        selected_images = [images[i] for i in selected_slices]
    else:
        # 중앙 슬라이스 선택
        center_idx = len(images) // 2
        selected_images = [images[center_idx]]

    return selected_images if len(selected_images) > 1 else selected_images[0]

    연동 포인트¶

    시스템 통합 방식 설명
    PACS DICOMweb API 표준 DICOMweb 프로토콜로 이미지 조회
    RIS FHIR/REST 분석 결과를 환자 기록에 자동 저장
    VNA DICOM + metadata 장기 보관 및 분석 결과 메타데이터 저장
    HIS HL7/FHIR 환자 정보 동기화

    API 연결 예시¶

    # 1. PACS에서 스터디 목록 조회
pacs_url = "https://pacs.example.com/dicomweb/studies"
headers = {"Authorization": "Bearer YOUR_TOKEN"}

response = requests.get(pacs_url, headers=headers)
studies = response.json()

# 2. 의미 있는 스터디 필터링
meaningful_studies = [
    s for s in studies
    if s.get("Modality") == "CT"  # CT 스터디만
]

# 3. 스터디에서 인스턴스 목록 조회
for study in meaningful_studies:
    study_uid = study["StudyInstanceUID"]

    instances_url = f"{pacs_url}/{study_uid}/instances"
    response = requests.get(instances_url, headers=headers)
    instances = response.json()

    # 4. 각 인스턴스에서 이미지 추출
    for instance in instances:
        instance_uid = instance["SOPInstanceUID"]

        # 5. MedGemma에 전송
        dicom_input = {
            "image_dicom": {
                "dicomweb_uri": f"{pacs_url}/{study_uid}/instances/{instance_uid}",
                "instance_uid": instance_uid
            }
        }

        result = model.predict(
            input=dicom_input,
            prompt="이 CT 이미지를 분석하고 병변을 식별해주세요.",
            temperature=0.7
        )

        # 6. 결과를 PACS에 저장
        # (DICOM Annotations 또는 QIDO-RS 결과로 저장)
        print(f"{study_uid}/{instance_uid}: {result.response}")
