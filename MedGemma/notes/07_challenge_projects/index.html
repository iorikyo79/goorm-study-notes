    1. 진단 및 영상 분석 (Diagnostic & Imaging)¶

    1.1 방사선/영상의학 (Radiology)¶

    프로젝트명 키워드 요약 링크
    NaijaScan-VLM 나이지리아, X-ray, 자동 리포트 나이지리아 진단 격차 해소를 위한 X-ray 자동 리포팅 Kaggle
    Safe Multimodal Radiology Triage 방사선, 트리아지, 보수적 분석 흉부 X-ray 분석으로 방사선 워크플로우 지원 Kaggle
    ExplainMyXray 해석 가능한 AI, 병변 위치화 MedGemma로 병변 위치 파악 가능한 X-ray 분석 Kaggle
    PocketRad 엣지 배포, 교육, MedSigLIP MedSigLIP + MedGemma 4B로 흉부 X-ray 교육 Kaggle
    CXR-Insight 리포트 요약, 구조화 흉부 X-ray 리포트 구조화 및 요약 Kaggle
    Lumina Thorax Triage CDSS, 워크리스트 우선순위 흉부 영상 트리아지 및 워크리스트 관리 Kaggle

    1.2 병리학 (Pathology)¶

    프로젝트명 키워드 요약 링크
    PathoAssist 병리학, AI 어시스턴트 현대 병리학을 위한 AI 어시스턴트 Kaggle
    Agentic Histopathology Assistant HAI-DEF, 종양 탐지 Path Foundation + MedGemma로 종양 탐지 Kaggle
    ANTONI-Alpha WSI, Gigapixel, VQA Gigapixel 병리 이미지 VQA 시스템 Kaggle
    Pathology Copilot WSI, AI Whole Slide Image 분석 AI Kaggle

    1.3 피부과 (Dermatology)¶

    프로젝트명 키워드 요약 링크
    DermAssist 피부과, 웹 기반 피부 상태 설명 웹 AI 어시스턴트 Kaggle
    Dermatology user-friendly assistant 피부과, 시각 검사 피부과 초기 시각 검사 어시스턴트 Kaggle
    Skin Disease Detection 피부 질환, 보편적 AI 모든 피부톤/인종/연령 지원 피부 질환 탐지 Kaggle
    DermaCheck iOS, 파인튜닝, LangGraph 파인튜닝 MedGemma로 피부 모니터링 iOS 앱 Kaggle
    BabyGuard 유아 피부, 오프라인, 양자화 유아 피부 상태 즉시 트리아지 모바일 앱 Kaggle
    EWAAST 압력 궤양, 피부톤 공정성 모든 피부톤에 공정한 압력 궤양 평가 Kaggle

    프로젝트명 키워드 요약 링크

    OcularGuard 수술 후 안과, IOP, 다중 모달 수술 후 안과 환자 트리아지 AI Kaggle
    Offline Edge AI for Preventable Blindness 실명 예방, DR 스크리너 당뇨망막병증 스크리닝 엣지 AI Kaggle

    우리 회사 연구와의 연관성¶

    높은 연관성 (직접 활용 가능)¶

    1. 의료 영상 분석¶

    • Critical Imaging Copilot: 응급 영상 분석 + 의사 승인 게이트
    • ExplainMyXray: 병변 위치화 + 설명 가능성
    • PathoAssist: 병리 이미지 AI 어시스턴트
    • 적용: PACS/DICOM 통합, AI 보조 판독

    2. 임상 문서화 자동화¶

    • ClinScribe: 음성 → 구조화된 노트
    • TherapyScribe: OT 음성 → SOAP 노트
    • MedGemma StructCore: 자유 텍스트 → 구조화
    • 적용: EMR/EHR 문서화 자동화

    3. 다중 에이전트 시스템¶

    • Multi-Agent Architecture: 순차적 엣지 오케스트레이션
    • MedRec AI: 5-에이전트 임상 검사 해석
    • 적용: 도메인별 특화 에이전트 구축

    중간 연관성 (참고 가능)¶

    1. 로컬/엣지 배포¶

    • MedGemma 1.5-4b on Edge: llama.cpp + 4코어 CPU
    • HospitalAI: 4비트 양자화 로컬 실행
    • 적용: 오프라인 진단 보조, 데이터 프라이버시

    2. RAG 기반 임상 지원¶

    • Selene: ChromaDB + MedGemma
    • QTGuard: Safety-Gated RAG
    • 적용: 병원 지침 검색, 임상 Q&A

    3. 약물 안전¶

    • SilverGuard CDS: 노인 약물 오류 차단
    • QTGuard: QT 연장 약물 안전
    • 적용: 처방 오류 탐지, 약물 상호작용

    낮은 연관성 (참고용)¶

    1. 특수 환경¶

    • Marine Nurse AI: 해상 응급
    • MedEvac-Gemma: 전장 의료
    • SailingMedAdvisor: 원양 요트

    2. 특수 도메인¶

    • Microbiome-Immunotherapy: 마이크로바이옴
    • Eco-Evolutionary Control: 항생제 내성 관리
    • NTD-Assist: 열대 질환

    핵심 인사이트¶

    1. 에이전트 기반 아키텍처가 주류¶

    • 단일 모델 호출이 아닌 다중 에이전트 협업
    • LangGraph, MCP 도구 활용 증가
    • 도메인별 특화 에이전트 분산 처리

    2. 오프라인/엣지 배포 필수¶

    • Apple Silicon + MLX/Ollama 조합 일반화
    • 4비트 양자화로 리소스 제약 극복
    • CPU 전용 GGUF 모델 활용

    3. 안전 게이트 메커니즘 표준화¶

    • "진단/치료 권장 없음" 명시 필수
    • 의사 승인 게이트 도입
    • 하드코딩된 응급 탐지 레이어

    4. 저자원 환경 타겟팅¶

    • 농촌/개발도상국 의료 격차 해소
    • 피처폰/음성통화 지원
    • 현지 언어 지원 (벵골어, 불가리아어 등)

    5. 다중 모달리티 통합¶

    • 텍스트 + 이미지 + 오디오 결합
    • HeAR (건강 음향) 활용 증가
    • CGM, IOP, ECG 등 센서 데이터 통합

    추천 후속 작업¶

    1. 우선순위 프로젝트 심층 분석¶

    • Critical Imaging Copilot (응급 영상)
    • MedSci Agent (28개 MCP 도구)
    • QTGuard (Safety-Gated RAG)

    2. 기술 스택 실험¶

    • Apple Silicon + MLX 양자화
    • LangGraph 에이전트 오케스트레이션
    • ChromaDB + MedGemma RAG

    3. 실제 적용 시나리오 설계¶

    • EMR 문서화 자동화
    • PACS AI 보조 판독
    • 처방 오류 탐지 시스템
