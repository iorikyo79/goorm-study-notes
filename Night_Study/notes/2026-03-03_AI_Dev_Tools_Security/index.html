    AI 개발 도구 보안 가이드 (개인 계정용)¶

    작성일: 2026-03-03 (업데이트: 2026-03-03) 연구 유형: Night Study Lab 목적: 개인 계정으로 AI 개발 도구 사용 시 최소한의 보안 설정 가이드 대상 도구: GitHub Copilot, Cursor AI, Claude Code, Gemini CLI, Google Antigravity

    📋 연구 배경¶

    회사에서 AI를 활용한 개발을 활성화하기 위해 다양한 AI 개발 도구를 지원하려고 함. 보안 문제로 인해 보통 팀 계정이나 엔터프라이즈 계정을 사용하지만, 진입 장벽을 낮추기 위해 개인 계정을 사용하면서 최소한의 보안을 유지하는 방안을 연구.

    🔍 연구 결과 요약¶

    1. GitHub Copilot¶

    핵심 보안 설정: - 모델 학습: 기본 비활성화 (개인 계정에서는 활성화 불가) - 코드 스니펫 수집: 설정에서 "Allow GitHub to use my code snippets..." 체크 해제 - 공개 코드 매칭: Block 권장 - 코드 제외: # @generated 주석, .gitignore

    레퍼런스: GitHub Copilot Policies

    2. Cursor AI¶

    핵심 보안 정책: - 모델 학습: 기본 비활성화 - 예외: 보안 플래그, 명시적 피드백, 명시적 동의 시에만 - 코드 제외: .cursorignore 파일

    레퍼런스: Cursor Privacy Policy

    3. Claude Code¶

    핵심 보안 기능: - 권한 기반 아키텍처 (읽기 전용 기본) - 샌드박스 모드 (/sandbox) - 코드 제외: .claudeignore - SOC 2 Type 2, ISO 27001 인증

    레퍼런스: Claude Code Security

    4. Google Gemini Code Assist¶

    핵심 보안 설정: - 개인 계정: "Improve Gemini" 옵션 비활성화 - Vertex AI (기업용): 데이터 학습 사용 안 함 - 코드 제외: .gitignore 활용

    레퍼런스: Google AI Privacy

    5. Gemini CLI¶

    핵심 보안 정책: - 인증 방법에 따라 다른 정책 적용 - 개인 계정/API 무료: 모델 학습에 사용됨 (Usage Statistics 옵트아웃 필수) - Standard/Enterprise/API 유료/Vertex AI: 학습에 사용 안 됨 - 보안 인증: ISO 27001, SOC 1/2/3

    레퍼런스: Gemini CLI ToS & Privacy

    6. Google Antigravity¶

    핵심 보안 기능: - Terminal Execution Policy (Off/Auto/Turbo) - Review Policy (Always Proceed/Agent Decides/Request Review) - JavaScript Execution Policy (Browser 보안) - Allow List / Deny List 구성 - Browser URL Allowlist

    데이터 처리: - Gemini Code Assist for individuals와 동일 정책 - 기본적으로 모델 학습에 데이터 사용됨

    레퍼런스: Getting Started with Antigravity

    📁 팀별 코드 보호 가이드¶

    민감 코드 분류표¶

    분류 예시 조치
    극비 DB 연결 정보, API 키, 암호화 키 AI 도구 접근 완전 차단
    기밀 비즈니스 로직, 알고리즘 팀장 승인 후 제한적 사용
    내부 일반 코드, 문서 자유롭게 사용 가능
    공개 오픈소스, 공개 문서 제한 없음

    ✅ 보안 체크리스트¶

    개인 계정 설정¶

    • [ ] 모델 학습 비활성화 옵션 확인
    • [ ] 공개 코드 매칭 차단 (가능한 경우)
    • [ ] .gitignore에 민감한 파일 추가
    • [ ] 각 도구별 ignore 파일 생성

    프로젝트별¶

    • [ ] 프로젝트 루트에 ignore 파일 생성
    • [ ] 민감한 정보는 환경 변수로 관리
    • [ ] API 키, 비밀번호 등 절대 하드코딩하지 않음
