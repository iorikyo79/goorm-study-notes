    MedGemma 1.5 API 서버 구성 연구¶

    날짜: 2026년 3월 5일
    유형: 심야 연구
    태그: #AI #LLM #Medical #API #서버구성

    📋 개요¶

    다른 팀에서 요청하여 MedGemma 1.5를 서버에 설치하고, 외부 팀에서 API를 통해 판독문 평가(오탈자, 논리오류 탐지)를 테스트할 수 있도록 구성하는 방법 연구.

    🎯 목적¶

    • 판독문 평가: 오탈자, 논리오류 등 탐지
    • 이미지 처리: 하지 않음 (텍스트 전용)
    • API 서버: 외부 팀에서 쉽게 호출 가능한 구성

    🏆 핵심 결론¶

    추천 구성¶

    항목 추천
    모델 google/medgemma-27b-text-it (텍스트 전용)
    서빙 vLLM + Docker
    API OpenAI 호환 (/v1/chat/completions)
    하드웨어 RTX A6000 × 2 (48GB × 2)
    최소 하드웨어 RTX 4090 (24GB) + 4-bit 양자화
    라이선스 무료 (연구/상업적 사용 가능)

    📊 MedGemma 1.5 모델 정보¶

    모델 종류¶

    모델명 파라미터 타입 GPU 메모리
    medgemma-1.5-4b-it 4B 멀티모달 ~8GB
    medgemma-27b-text-it 27B 텍스트 전용 ~54GB
    medgemma-27b-it 27B 멀티모달 ~54GB

    성능 (텍스트)¶

    • MedQA: 69.1% (4B), 89.8% (27B)
    • EHRQA: 89.6% (1세대 대비 +22%)

    🛠️ API 서버 구축 가이드¶

    vLLM + Docker 배포¶

    # 모델 다운로드
huggingface-cli download google/medgemma-27b-text-it \
  --local-dir ./models/medgemma-27b-text-it

# Docker 실행
docker run --gpus all \
  -v $(pwd)/models:/models \
  -p 8000:8000 \
  vllm/vllm-openai:v0.9.0.1 \
  --model /models/medgemma-27b-text-it \
  --served-model-name medgemma \
  --tensor-parallel-size 2 \
  --max-model-len 8192

    API 호출 예시¶

    from openai import OpenAI

client = OpenAI(
    base_url="http://your-server:8000/v1",
    api_key="your-api-key"
)

response = client.chat.completions.create(
    model="medgemma",
    messages=[
        {"role": "system", "content": "당신은 의료 판독문 분석 전문가입니다."},
        {"role": "user", "content": "다음 판독문에서 오탈자와 논리적 오류를 찾아주세요..."}
    ]
)

    💾 GPU 메모리 최적화¶

    양자화 옵션¶

    방식 VRAM 품질 추천
    4-bit ~16GB 미미한 저하 ⭐⭐⭐⭐⭐
    8-bit ~29GB 거의 없음 ⭐⭐⭐⭐
    GGUF Q4_K_M ~16GB 낮음 ⭐⭐⭐⭐

    4-bit 양자화 코드¶

    from transformers import BitsAndBytesConfig

quantization_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype=torch.float16,
    bnb_4bit_use_double_quant=True,
    bnb_4bit_quant_type="nf4"
)

    ⚠️ 주의사항¶

    1. TGI 사용 자제: 2025년 12월부터 maintenance mode
    2. 임상 직접 사용 금지: HAI-DEF 라이선스 제한
    3. Transformers 버전: 4.50.0 이상 필요
    4. vLLM 이슈: 27B 모델 Docker 시작 멈춤 현식 보고됨
