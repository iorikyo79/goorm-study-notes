    02. 변환의 기술: PyTorch to ONNX (The Art of Conversion)¶

    ONNX를 사용하는 첫 단계는 "기존 모델을 ONNX 포맷으로 변환(Export)"하는 것입니다. 가장 많이 사용되는 PyTorch를 기준으로 변환의 핵심 메커니즘을 알아봅니다.

    1. Tracing vs Scripting¶

    PyTorch 모델을 ONNX로 변환하는 방법은 크게 두 가지가 있습니다.

    1.1 Tracing (추적) - 가장 일반적¶

    • 원리: "더미 데이터(Dummy Input)"를 모델에 흘려보내고, 그 데이터가 지나가는 경로(연산 순서)를 그대로 녹화합니다.
    • 장점: 대부분의 딥러닝 모델(ResNet, BERT 등)에서 잘 동작하며 사용이 쉽습니다.
    • 단점: if, loop 같은 동적 제어문(Control Flow)이 데이터 값에 따라 달라지는 경우, 녹화 당시의 경로만 고정되어 버립니다. (동적 흐름이 사라짐)

    1.2 Scripting (스크립팅)¶

    • 원리: PyTorch 코드를 직접 분석(Compilation)하여 그래프를 만듭니다 (TorchScript).
    • 장점: 동적 제어 흐름(if, for)을 보존할 수 있습니다.
    • 단점: 작성 난이도가 높고, 지원되지 않는 Python 문법이 많습니다.

    💡 실무 팁: 95% 이상의 경우 Tracing 방식을 사용합니다. GLiNER 같은 NLP 모델도 Tracing으로 충분합니다.

    2. 핵심 코드: torch.onnx.export¶

    import torch

# 1. 모델 준비 (Eval 모드 필수!)
model.eval()

# 2. 더미 입력 생성 (모델이 기대하는 형상과 같아야 함)
dummy_input = torch.randn(1, 3, 224, 224) 

# 3. 변환 실행
torch.onnx.export(
    model,                      # 실행할 모델
    dummy_input,                # 모델 실행을 위한 가짜 데이터
    "model.onnx",               # 저장될 파일명
    opset_version=17,           # ONNX 연산자 버전 (호환성 중요)
    input_names=['input'],      # 입력 노드 이름 (나중에 맵핑할 때 씀)
    output_names=['output'],    # 출력 노드 이름

    # ★ 중요: 가변 길이 설정 (Batch Size, Sequence Length 등)
    dynamic_axes={
        'input': {0: 'batch_size', 2: 'height', 3: 'width'},
        'output': {0: 'batch_size'}
    }
)

    3. Dynamic Axes (동적 축) - 매우 중요!¶

    Tracing 방식은 입력 데이터의 크기까지 "상수(Constant)"로 박제해버리는 특성이 있습니다. 만약 dummy_input의 배치가 1이었다면, 변환된 ONNX 모델도 오직 배치 크기 1만 받을 수 있게 됩니다.

    이를 방지하기 위해 dynamic_axes 옵션을 사용합니다. * "이 차원(dimension)은 나중에 바뀔 수 있어!" 라고 알려주는 마킹입니다. * 주로 0번 축(Batch Size)과 NLP의 1번 축(Sequence Length)을 동적으로 설정합니다.

    4. 변환 후 검증 (Validation)¶

    변환이 잘 되었는지 확인하려면 onnx 라이브러리를 사용합니다.

    import onnx

# 모델 로드
onnx_model = onnx.load("model.onnx")

# 구조적 문제 체크 (Graph 연결, 입출력 형상 등)
try:
    onnx.checker.check_model(onnx_model)
    print("✅ ONNX 모델 무결성 확인 완료!")
except onnx.checker.ValidationError as e:
    print(f"❌ 모델 에러: {e}")
