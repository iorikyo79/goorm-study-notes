    paper-banana 스킬 교육 가이드¶

    생성일: 2026-03-23 소스: PaperBanana: Automating Academic Illustration for AI Scientists

    1. 개요¶

    PaperBanana는 텍스트 설명에서 출판 품질의 학술 다이어그램과 통계 플롯을 자동으로 생성하는 에이전트 프레임워크입니다. 다중 에이전트 파이프라인과 반복적 개선을 사용하여 텍스트 설명을 연구 논문 및 프레젠테이션에 적합한 전문 다이어그램으로 변환합니다.

    한 줄 요약: 텍스트를 입력하면 AI가 자동으로 논문용 다이어그램/그래프를 생성하는 도구

    핵심 기능: - 텍스트 설명에서 방법론 다이어그램 생성 - CSV/JSON 데이터에서 통계 플롯 생성 - 매니페스트 파일에서 일괄 생성 - 인간 참조 대비 품질 평가 - 다중 AI 제공자 지원 (OpenAI, Google Gemini)

    2. 작동 원리¶

    2.1 전체 프로세스¶

    [텍스트 입력 / 데이터 파일]
    ↓
[Phase 1: Retrieval] - 참조 예시 검색
    ↓
[Phase 1: Planning] - VLM이 다이어그램 설명 생성
    ↓
[Phase 2: Generation] - 이미지 생성 모델이 다이어그램 생성
    ↓
[Phase 3: Critique] - 품질 평가 및 피드백
    ↓
[반복 또는 완료]
    ↓
[최종 다이어그램 출력]

    2.2 핵심 알고리즘/로직¶

    실제 실행 로그 기반: 

    2026-03-23 16:33:08 [info] Creating VLM provider          model=gemini-2.0-flash provider=gemini
2026-03-23 16:33:08 [info] Creating image gen provider    model=gemini-3-pro-image-preview provider=google_imagen
2026-03-23 16:33:08 [info] Pipeline initialized           image_gen=google_imagen run_id=run_20260323_163308_6db321 vlm=gemini
2026-03-23 16:33:08 [info] Starting generation            context_length=466 diagram_type=methodology
2026-03-23 16:33:08 [info] Phase 1: Retrieval
2026-03-23 16:33:08 [warning] No reference index found    path=data/reference_sets
2026-03-23 16:33:08 [info] Phase 1: Planning
2026-03-23 16:33:08 [info] Running planner agent          context_length=466 num_examples=0 num_images=0

    작동 과정: 1. VLM (Vision Language Model): Gemini-2.0-flash가 텍스트를 다이어그램 설명으로 변환 2. Image Generation: Google Imagen이 설명을 기반으로 이미지 생성 3. Critic Agent: 생성된 이미지 품질 평가 4. Iterative Refinement: 만족할 때까지 반복 (기본 3회)

    2.3 기술 스택¶

    • 언어: Python 3.10+
    • 주요 라이브러리:
    • google-genai (Google Gemini API)
    • tenacity (재시도 로직)
    • rich (CLI UI)
    • 의존성:
    • VLM: Gemini-2.0-flash 또는 OpenAI GPT-4V
    • Image Gen: Google Imagen 또는 DALL-E 3

    3. 스킬 사용법¶

    3.1 기본 명령어¶

    다이어그램 생성: 

    paperbanana generate --input method.txt --caption "다이어그램 설명"

    통계 플롯 생성: 

    paperbanana plot --data results.csv --intent "그래프 목적"

    일괄 생성: 

    paperbanana batch --manifest manifest.yaml

    3.2 파라미터 설명¶

    generate 명령어¶

    파라미터 타입 필수 설명 기본값
    --input, -i string ✅ 방법론 텍스트 파일 경로 -
    --caption, -c string ✅ 그림 캡션 -
    --output, -o string ❌ 출력 이미지 경로 자동 생성
    --iterations, -n int ❌ 개선 라운드 수 3
    --auto flag ❌ 만족할 때까지 자동 반복 false
    --optimize flag ❌ 입력 최적화 활성화 false
    --continue flag ❌ 이전 실행에서 계속 false
    --feedback string ❌ 사용자 피드백 -

    plot 명령어¶

    파라미터 타입 필수 설명 기본값
    --data, -d string ✅ CSV/JSON 데이터 파일 경로 -
    --intent string ✅ 플롯의 전달 의도 -
    --output, -o string ❌ 출력 이미지 경로 자동 생성

    3.3 옵션¶

    • --optimize: 입력 텍스트를 최적화하여 품질 향상
    • --auto: Critic 에이전트가 만족할 때까지 자동 반복
    • --continue --feedback "...": 이전 결과에 피드백을 반영하여 개선

    4. 실제 예시¶

    ⚠️ 주의¶

    모든 예시는 실제 실행 결과입니다. 가상 데이터가 아닙니다.

    현재 상태: API 키 미설정으로 실제 이미지 생성은 실패했으나, 명령어 구조와 에러 메시지를 확인했습니다.

    예시 1: 기본 다이어그램 생성¶

    사용 상황: 연구 논문에서 방법론을 시각화해야 할 때

    입력 파일 (method.txt): 

    Our Medical Report Converter framework consists of three main components:

1. DICOM Parser: Extracts metadata and pixel data from DICOM files
2. NLP Processor: Uses transformer-based models to extract clinical entities
3. Report Generator: Converts structured data into HL7 FHIR format

The input DICOM file passes through the parser, then the NLP processor
extracts findings and impressions, and finally the report generator
produces a structured medical report.

    명령어: 

    paperbanana generate \
  --input method.txt \
  --caption "Medical Report Converter Architecture" \
  --output scenario_1_diagram.png

    실행 결과:

    예시 2: 통계 그래프 생성¶

    사용 상황: 실험 결과를 비교하는 막대 그래프가 필요할 때

    입력 파일 (results.csv):

Vision Transformer,89.1,0.87,68
Our Method,92.3,0.91,41

    명령어: 

    paperbanana plot \
  --data results.csv \
  --intent "Bar chart comparing model accuracy and F1 score across different architectures" \
  --output scenario_3_plot.png

    설명: - CSV 데이터가 정상적으로 로드됨 - diagram_type=statistical_plot으로 자동 설정 - API 키 설정 후에는 실제 그래프 생성 가능

    예시 3: API 키 설정 (필수)¶

    사용 상황: 처음 사용할 때 또는 API 키 갱신 시

    명령어: 

    paperbanana setup

    예상 동작: - 대화형 설정 마법사 시작 - Google AI Studio 또는 OpenAI에서 API 키 입력 - 환경 변수 또는 설정 파일에 저장

    수동 설정 방법: 

    # Google Gemini (무료 티어)
export GOOGLE_API_KEY="your-key-here"

# OpenAI (유료)
export OPENAI_API_KEY="your-key-here"

    5. 트러블슈팅¶

    ⚠️ 실제 겪은 문제 기반¶

    문제 1: API 키 미설정¶

    증상: 

    ValueError: No API key was provided. Please pass a valid API key.
Learn how to create an API key at https://ai.google.dev/gemini-api/docs/api-key.
RetryError: RetryError[<Future at 0x7e90943d3e50 state=finished raised ValueError>]

    원인: - 환경 변수에 GOOGLE_API_KEY 또는 OPENAI_API_KEY가 설정되지 않음 - paperbanana setup을 실행하지 않음

    해결 방법: 

    # 방법 1: 설정 마법사 사용
paperbanana setup

# 방법 2: 환경 변수 직접 설정
export GOOGLE_API_KEY="your-key-here"

# 방법 3: ~/.bashrc 또는 ~/.zshrc에 추가
echo 'export GOOGLE_API_KEY="your-key-here"' >> ~/.bashrc
source ~/.bashrc

    예방 팁: - API 키는 안전한 곳에 백업해둘 것 - Google AI Studio 무료 티어를 먼저 사용해볼 것

    문제 2: google-genai 라이브러리 호환성 문제¶

    증상: 

    AttributeError: 'BaseApiClient' object has no attribute '_async_httpx_client'
Task exception was never retrieved

    원인: - google-genai 라이브러리 버전 불일치 - PaperBanana가 사용하는 API와 설치된 버전 간 호환성 문제

    해결 방법: 

    # google-genai 재설치
pip uninstall google-genai -y
pip install google-genai --upgrade

# 또는 PaperBanana 재설치
pip uninstall paperbanana -y
pip install paperbanana --upgrade

    예방 팁: - 가상 환경을 사용하여 의존성 격리 - requirements.txt에 버전 고정

    문제 3: Reference Index 없음¶

    증상: 

    [warning] No reference index found       path=data/reference_sets
[warning] No reference candidates available, returning empty list

    원인: - 참조 예시 데이터셋이 설치되지 않음 - 첫 실행 시 정상적인 경고

    해결 방법: 

    # 참조 데이터셋 다운로드 (선택사항)
# 품질 향상을 위해 사용하지만 필수는 아님

    설명: - Reference Index가 없어도 동작함 - 품질 향상을 위한 선택적 기능

    6. 확장 아이디어¶

    6.1 집사의 업무에 적용¶

    1. MoltsBot 연구 노트: 실험 파이프라인을 다이어그램으로 시각화
    2. 블로그 포스트: deep-blog-writer와 결합하여 기술 블로그에 다이어그램 추가
    3. 프레젠테이션: 연구 발표 자료에 사용할 방법론 다이어그램 생성

    6.2 다른 스킬과의 조합¶

    • deep-blog-writer + paper-banana: 기술 블로그에 다이어그램 자동 추가
    • video-subtitle-extractor + paper-banana: 영상 내용을 다이어그램으로 요약
    • agent-research + paper-banana: 리서치 결과를 시각화하여 보고서 작성

    6.3 향후 개선 가능성¶

    • 한글 캡션 지원 (현재는 영어 최적화)
    • 의료 영상 특화 템플릿 추가
    • DICOM 메타데이터에서 자동 다이어그램 생성
