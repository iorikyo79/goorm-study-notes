    research-to-practice 스킬 교육 가이드¶

    생성일: 2026-03-23 소스: Claude Blue (실리콘밸리 AI 우울증) + 박형준님 포스트

    1. 개요¶

    한 줄 요약: 새로운 논문/방법론/오픈소스를 발견하면, 실행 에이전트는 스킬로 만들고, 학습 에이전트는 직접 사용해보고 교육자료를 생성합니다.

    핵심 기능: - 논문, GitHub 저장소, 기술 블로그 → OpenClaw 스킬로 자동 변환 - 실행 + 학습 에이전트 병렬 처리로 시간 단축 - 실제 실행 결과 기반 교육자료 생성 (할루시네이션 방지) - 연구노트/신규스킬/에 자동 저장

    2. 작동 원리¶

    전체 프로세스¶

    논문/오픈소스 URL 입력
    ↓
├── 🔧 실행 에이전트 (Skill Creator)
│   ├── 내용 분석 (README, 코드)
│   ├── 스킬 생성 (skills/[이름]/)
│   ├── 의존성 설치 (pip, npm)
│   └── 실제 테스트 → 결과물 저장
│
└── 📚 학습 에이전트 (Educator + Reviewer)
    ├── 스킬 직접 사용 (3개 시나리오)
    ├── 실행 에이전트 결과 검수
    ├── 실제 실행 결과 기반 교육자료 작성
    └── 연구노트/신규스킬/에 저장

    듀얼 에이전트 워크플로우¶

    메타 선배의 방식 (Claude Blue 글 참조): 

    새 업무 받음
    ↓
동시에 2개 에이전트 실행
    ├── 실행: "야, 먼저 시작해" (결과물 생성)
    └── 학습: 업무가 뭔지 나에게 설명

    research-to-practice 적용: 

    새 논문/오픈소스 발견
    ↓
동시에 2개 에이전트 실행
    ├── 실행: 스킬로 만들어서 "딸깍" 사용 가능하게
    └── 학습: 직접 써보고 검수하고 교육자료 작성

    3. 스킬 사용법¶

    기본 명령어¶

    집사: "이거 스킬로 만들어줘: [URL]"
집사: "이 논문 분석해서 스킬로 등록해줘"
집사: "이 오픈소스 바로 써먹게 해줘"

    파라미터¶

    입력 타입 설명
    URL string 논문, GitHub, 기술 블로그 링크
    설명 string (선택) 추가 컨텍스트

    옵션¶

    • 실행 에이전트만 실행: --executor-only
    • 학습 에이전트만 실행: --educator-only (이미 스킬이 있는 경우)

    5. 트러블슈팅¶

    문제 1: API 키 할당량 초과¶

    증상: 

    ClientError: 429 RESOURCE_EXHAUSTED
Quota exceeded for metric: generate_content_free_tier_requests

    원인: - Free tier API 키 사용 중 - 일일/분당 요청 한도 초과

    해결 방법: 1. Google AI Studio에서 Pro 계정용 API 키 발급 2. 환경 변수 업데이트: 

    export GOOGLE_API_KEY="새로운-Pro-API-키"
    3. 1분 대기 후 재시도

    예방 팁: - Pro 계정 사용 (Free tier보다 133배 더 많은 요청 가능) - 배치 처리로 한 번에 여러 작업 수행

    문제 2: 스킬 생성 실패 (pip install 에러)¶

    증상: 

    ERROR: Could not find a version that satisfies the requirement

    원인: - 패키지 이름 오류 - Python 버전 호환성 문제 - 시스템 의존성 부족

    해결 방법: 1. GitHub README에서 정확한 설치 방법 확인 2. Python 버전 확인 (3.10+ 필요한 경우 많음) 3. 시스템 라이브러리 설치: 

    sudo apt-get install [필요한-라이브러리]

    문제 3: 할루시네이션 (가상 데이터)¶

    증상: - 교육자료에 실제 존재하지 않는 예시 - 실행해보지 않은 기능 설명

    원인: - 학습 에이전트가 스킬을 직접 사용하지 않음 - 문서만 읽고 추측으로 작성

    해결 방법: - research-to-practice 스킬은 자동으로 방지: - 학습 에이전트가 반드시 스킬 직접 호출 - 실제 실행 결과만 교육자료에 포함 - 실행 로그 기반으로 작성

    6. 확장 아이디어¶

    6.1 집사의 업무에 적용¶

    1. 의료 AI 논문 리서치
    2. 새로운 Segmentation 모델 논문 발견
    3. "이거 스킬로 만들어줘" → 바로 테스트 가능

    4. 우리 데이터에 적용 가능성 평가

    5. 판독문 오탈자 검출

    6. 관련 오픈소스 발견 시 스킬로 변환

    7. GLM-5와 결합하여 파이프라인 구축

    8. KIMES 2026 발표 자료

    9. paper-banana로 발표용 다이어그램 자동 생성
    10. Medical Report Converter 아키텍처 시각화

    6.2 다른 스킬과의 조합¶

    • deep-blog-writer + research-to-practice:

    • 새 논문 → 스킬로 변환 → 블로그 작성 (Why/How/So What)

    • agent-research + research-to-practice:

    • 4개 에이전트로 논문 리서치 → 스킬로 변환

    • video-subtitle-extractor + research-to-practice:

    • YouTube 강의 → 자막 추출 → 스킬로 변환
